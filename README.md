Звіт про розробку гри «Симулятор Маріо»

**1. Персонажі та ігрова логіка:**
*   **Маріо та вороги:** У грі реалізовано повноцінний рух головного персонажа та ворогів (Купа, Гумба), які автоматично бігають по рівню.
*   **Система очок:** Гравець отримує бали за збивання ворогів, збирання монеток та підбирання гриба.
*   **Бонуси:** Реалізовано механіку «Гриба», який робить Маріо великим, та «Зірки», яка дає тимчасову невразливість, підвищує швидкість та силу стрибка.

**2. Екрани та інтерфейс:**
*   **Стартове меню:** Створено головний екран, де можна ввести ім'я гравця та почати гру або вийти з неї.
*   **Перемога та поразка:** Реалізовано фінальні вікна, які з’являються при досягненні фінішу або втраті всіх життів. З цих вікон можна перезапустити рівень або повернутися в меню.
*   **Таблиця рекордів:** Гра зберігає ім'я та найкращий результат гравця.

Гра повністю адаптована для роботи на комп'ютері та на Android.
Для гри на телефоні додано екранний джойстик та спеціальну кнопку для стрибка.
